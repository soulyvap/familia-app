# Familia App

Familia App is a mobile application designed to provide resources and information for multicultural families in Finland. The app features announcements and informative card decks on various topics to support families in navigating multicultural challenges and opportunities.

## Features

- **Announcements**: Stay updated with the latest news and information relevant to multicultural families in Finland.
- **Informative Card Decks**: Explore decks of cards on topics such as raising a child in a multicultural family, cultural integration, and family support resources.
  - Users can swipe through the cards to learn more about each topic.
  - Track your progress as you go through the card decks.
- **Progress Tracking**: Keep track of the topics you have explored and your learning journey.

## Installation

### Prerequisites

Ensure you have the following installed on your system:

- Node.js (>= 14.0.0)
- npm (>= 6.0.0)
- Expo CLI (>= 5.0.0)

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/soulyvap/familia-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd familia-app
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the Expo development server:

   ```bash
   npx expo start
   ```

5. Run the app on your device:
   - Use the Expo Go app to scan the QR code displayed in the terminal or browser.
   - Alternatively, launch the app on an emulator for iOS or Android.

## Usage

1. Open the app on your mobile device.
2. View announcements for important news and updates.
3. Select a topic from the available card decks.
4. Swipe through the cards to read and learn about the topic.
5. Monitor your progress as you complete the card decks.
